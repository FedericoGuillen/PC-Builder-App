Guías de Componentes

Conocé las partes de una computadora, descubrí para qué sirve cada componente y aprendé qué tener en cuenta antes de elegirlos para tu próximo armado.

Motherboard

La placa principal que conecta y permite la comunicación entre todos los componentes de la PC.

Ver guía →

Fuente de poder

Suministra energía eléctrica a todos los componentes y debe tener potencia suficiente para el equipo.

Ver guía →

Disipadores

Ayudan a controlar la temperatura del procesador y otros componentes mediante refrigeración.

Ver guía →

Procesadores

Es el cerebro de la computadora: ejecuta instrucciones y procesa las tareas del sistema.

Ver guía →

Cableado y gabinete

El gabinete aloja los componentes y el cableado permite conectarlos correctamente.

Ver guía →

Periféricos

Dispositivos externos como teclado, mouse, monitor y auriculares que permiten interactuar con la PC.

Ver guía →

Memorias RAM

Almacenan temporalmente los datos que utiliza el procesador mientras ejecuta tareas.

Ver guía →

Pila CMOS

Mantiene el reloj del sistema y ciertos ajustes de configuración de la BIOS cuando la PC está apagada.

Ver guía →

Redes y audio

Permiten conectar la computadora a internet y gestionar la entrada y salida de sonido.

Ver guía →

Tarjeta gráfica

Procesa y genera las imágenes que aparecen en el monitor. Es fundamental para videojuegos.

Ver guía →

Almacenamiento

Guarda permanentemente el sistema operativo, programas, archivos y videojuegos.

Ver guía →
